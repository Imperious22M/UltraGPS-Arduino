UltraGPS Arduino Firmware¶

Arduino firmware for the St. Mary's University UltraGPS positioning system, developed as part of graduate research.

The repository holds the two Arduino scripts that run on the Arduino Uno's that are the physical backbone of the system. The base station accepts single-letter commands over USB serial, tells the transmitter over a 2.4 GHz radio link when to fire, times the ultrasonic echoes returned by six receivers, and prints the resulting tick counts back over serial. The transmitter station listens for those radio packets, keeps its timer phase-locked to the base station, and drives the ultrasonic transmitter.

The base station is the board that the UltraGPS Ground Station program (UltraGpsXY) talks to over USB serial.

At a glance¶
Sketches base-station/, transmitter-station/
Board Arduino Uno (ATmega328P, 16 MHz)
Framework Arduino, built with PlatformIO (platform = atmelavr)
Depedency nRF24/RF24 (pulled in automatically)
Serial 38400 bps, 8N1
Radio nRF24L01+, channel 100, 1 Mbps, 8-byte fixed payload
Pulse rate 10 Hz (Timer1, CTC mode)
Receivers 6, on A0–A5

Quick start¶

Every release ships prebuilt .hex images and a zip of the sketch sources on the Releases page. You do not need a toolchain to flash a release — arduino-cli alone will do it:

arduino-cli upload -p /dev/ttyACM0 -b arduino:avr:uno \
    --input-file ultragps-base-station-v1.0.hex

To build from source instead, see Installation and Uploading.
